## BLOCK
- **B1 — run_seq fence declared but never enforced.** `SuspendRoute` bumps
  `run_seq` but no query reads it; a stale/duplicate *wait* continuation can lock +
  resume an already-advanced route. → **FIX-NOW** (store run_seq on the
  continuation at suspend; `AND run_seq = $N` on acquire).
- **B2 — Lua sandbox: tight loop hangs; load/collectgarbage/string.format/
  table.concat reachable.** `SetContext` only checks at call boundaries, so
  `while true do end` never aborts. → **FIX-NOW** (instruction-count debug hook
  aborting on ctx.Err(); nil load/loadstring/collectgarbage; bound format/concat).
- **B3 — Region-internal suspension not resumable.** A wait/reservation/input
  inside loop/parallel/try bubbles a top-level cursor that loses iteration/branch/
  scope. → **FIX-NOW** (validate: reject suspending nodes inside regions — v0.2 is
  top-level only).
- **B4 — Branch-port cardinality unchecked.** Missing/dup/unknown port labels pass
  validate; runtime then silently "completes". → **FIX-NOW** (per-kind required-port
  validation + reject dup/extra unlabeled outs).
