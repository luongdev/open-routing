<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config JSONB textarea → API | Arbitrary JSON object; JSON.parse validates syntax; server validates schema constraints |
| adapter_type freeform text → API | No enum; server stores verbatim; ajv max-length enforced client-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11-01 | Tampering | config JSONB injection (XSS via stored JSON value) | mitigate | Lit renders config display using html template literals (auto-escaping); JSON.stringify output is text not raw HTML; no innerHTML with config values |
| T-06-11-02 | Tampering | Oversized config payload causing server DoS | mitigate | Server enforces JSONB column size limit; ajv schema maxProperties/additionalProperties applied if spec defines them; 413 shown as sl-alert |
| T-06-11-03 | Information Disclosure | Adapter config may contain credentials/tokens | accept | Admin-only page (org_id auth via X-Org-Id); credential exposure is inherent to adapter config management; no logging of config values in client code |
| T-06-11-SC | Tampering | No new npm installs in this plan | accept | Uses packages from Plan 06-01 legitimacy audit |
</threat_model>
