<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| or-queue-picker selection → channel API | queue ID is org-scoped UUID; server validates cross-org via X-Org-Id |
| null default_queue_id → API body | Nullable field; null must be serialized explicitly (not omitted) to clear |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-10-01 | Tampering | channel_type enum injection (arbitrary string via DevTools) | mitigate | ajv validateCreateChannel/validateUpdateChannel enforces enum; server validates independently; 422 on invalid value |
| T-06-10-02 | Tampering | default_queue_id set to cross-org queue UUID | mitigate | Server enforces X-Org-Id middleware + CROSS_ORG error code (D-54); client has no cross-org access |
| T-06-10-03 | Information Disclosure | or-queue-picker exposes all queue IDs and names | accept | Queues are org-scoped data visible to admin; read access is required by design |
| T-06-10-04 | Denial of Service | or-queue-picker unbounded search load | mitigate | limit=25 + cursor pagination; 300ms debounce prevents keystroke-per-request |
| T-06-10-SC | Tampering | No new npm installs in this plan | accept | Uses packages from Plan 06-01 legitimacy audit |
</threat_model>
