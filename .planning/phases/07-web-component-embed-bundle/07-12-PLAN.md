`require.resolve` and `import` semantics.

a SECOND library entry `./hash-router-adapter` so the shell could

(packages/ui → @open-routing/embed/hash-router-adapter → packages/ui).

constructs HashRouterAdapter and injects it into shell.routerAdapter.

single dist/embed.js.

Purpose: This is the EMBED-01 acceptance gate (bundle exists, single
ES module, ≤ 70 KB gzipped). Without this verification, the build
pipeline is theoretical — Wave 0 + Wave 1 + Wave 2 work could pass
unit/e2e tests but the actual `dist/embed.js` artifact could be
broken.
Output: package.json finalized; build + pack:dry artifacts validated.

artifacts exist only at CI/dev time — that's intentional per D7-15.
