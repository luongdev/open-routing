<objective>
Install **Frankenstyle v0.3.8** (the v3 rebrand of Franken UI by the same
author — sveltecult.com) and Tailwind v4 in `packages/ui` and `apps/admin`.
Frankenstyle ships:

- 445 uk-* utility/component classes (preserved from UIkit/v2 conventions)
- Lit-based Hardened Web Components (HWC) — `<uk-modal>`, `<uk-icon>`,
  `<uk-theme-switcher>` etc. — registered via IIFE side-effect bundles
- Built-in lucide icon support via `<uk-icon icon="home">`
- Tailwind v4 native (uses `@theme` directives, OKLCh color space)

**Why Frankenstyle v0.3.8 (not franken-ui v2.1.2)**: v2 was renamed in
the v3 release ~2026-05-05. Same author, same philosophy, much more
mature (built-in lucide + tiptap + apexcharts etc, Lit 3.3.1, Tailwind 4
native). v2 (franken-ui) is deprecated.

**Out of scope (do NOT do in this plan):**
- Customize the palette (07-w0-02 owns Tailwind v4 `@theme` directives)
- Build playground (07-w0-03)
- Build any wrapper or migrate existing components
- Remove Shoelace (07-w0-30)
</objective>

<execution_context>
Phase 7 W0.0 foundation; all other W0.0 plans block on this.

Frankenstyle distribution map (from tarball inspection):
- `frankenstyle/css/frankenstyle-kit.css` — main kit CSS (use this with Tailwind)
- `frankenstyle/css/frankenstyle-kit-standalone.css` — for use WITHOUT Tailwind (we use Tailwind, so skip)
- `frankenstyle/js/hwc-components.iife.js` — IIFE bundle registering all uk-* HWC elements
- `frankenstyle/js/hwc-icon.iife.js` — `<uk-icon>` registration (separate to allow lazy loading; we load it eagerly with components)
- `frankenstyle/js/hwc-chart.iife.js` — chart HWC (defer; chart not in W0.0 scope)
- Export map: `"./css/frankenstyle-kit.css"`, `"./js/*": "./dist/js/*.js"` — both work
</execution_context>

## Step 5: Vite config

side-effect imports do everything. Add Tailwind v4 plugin only:

```ts

export default defineConfig({
  plugins: [
    tailwindcss(),
    // ...existing plugins
  ],
});
```
