**Lifecycle — firstUpdated (Iteration-2 BLOCKER #1 wiring):**

```typescript
override firstUpdated(_changed: PropertyValues): void {
  // Iteration-2 BLOCKER #1: typed-interface seam. embed-element
  // constructs HashRouterAdapter (parameterless), assigns it to the
  // shell's public routerAdapter property BEFORE flipping
  // routing-mode='hash'. Shell's own firstUpdated calls
  // adapter.start(this._routes) — adapter receives Routes via the
  // typed method, never reaches into shell internals.
  this._tryWireHashAdapter();
}

private _tryWireHashAdapter(): void {
  if (!this._client) return;
  const shellEl = this._shellEl;
  if (!shellEl) return;
  if (this._hashAdapter) return;
  this._hashAdapter = new HashRouterAdapter();
  shellEl.routerAdapter = this._hashAdapter;
  shellEl.routingMode = 'hash';
}
```

The `_tryWireHashAdapter` is guarded: only wires when (1) a client is
built (no validation error), (2) the shell element is mounted (the
@query decorator finds it after render), and (3) we haven't already
wired this instance. If the shell hasn't rendered yet (e.g., on the
very first render while `_validationError` is set), no wiring
happens; subsequent updates re-attempt via `updated()`.

**Private methods:**

```typescript
private _validateAndBuildClient(): void {
  if (!this.orgId) {
    this._validationError = 'org-id attribute required';
    this._client = null;
    return;
  }
  if (!UUIDV7_PATTERN.test(this.orgId)) {
    this._validationError = 'Invalid org-id attribute (expected UUIDv7)';
    this._client = null;
    return;
  }
  this._validationError = null;
  this._client = createApiClient({
    baseURL: this.apiBaseUrl,
    getOrgId: () => this.orgId,
  });
  this._client.use(this._buildAuthExpiredMiddleware());
}

private _buildAuthExpiredMiddleware(): Middleware {
  return {
    onResponse: async ({ response, request }) => {
      if (response.status !== 401) return response;
      let requestId = '';
      try {
        const body = await response.clone().json();
        requestId = (body && typeof body === 'object' && 'request_id' in body && typeof body.request_id === 'string')
          ? body.request_id : '';
      } catch {
        // body not JSON; preserve empty requestId
      }
      const path = new URL(request.url).pathname;
      this._authExpired = { requestId, path };
      this.dispatchEvent(new CustomEvent('open-routing:auth-expired', {
        detail: { statusCode: 401, requestId, path },
        bubbles: true,
        composed: true,
      }));
      return response;
    },
  };
}

private _parseTheme(): void {
  if (!this.theme) {
    this._parsedTheme = '';
    return;
  }
  if ((NAMED_THEMES as readonly string[]).includes(this.theme)) {
    this._parsedTheme = this.theme as NamedTheme;
    return;
  }
  try {
    const parsed = JSON.parse(this.theme);
    if (parsed && typeof parsed === 'object' && !Array.isArray(parsed)) {
      // Reject prototype-pollution attempts (V8 — Tampering threat)
      delete (parsed as Record<string, unknown>).__proto__;
      this._parsedTheme = parsed as Record<string, string>;
      return;
    }
  } catch {
    // fall through to or-light default
  }
  this._parsedTheme = 'or-light';
}

private _dispatchRequestContext(): void {
  this.dispatchEvent(new CustomEvent('open-routing:request-context', {
    detail: {
      orgId: this.orgId,
      apiBaseUrl: this.apiBaseUrl,
      theme: this.theme,
      modules: this.modules,
    },
    bubbles: true,
    composed: true,
  }));
}

private _dismissAuthExpired(): void {
  this._authExpired = null;
}
```

**Critical Phase 7 implementation notes:**

1. Shadow DOM mode is `'open'` — Lit's default. CONTEXT Discretion
   recommends open so Playwright assertions + host querySelector
   debugging work. No `attachShadow` override needed.

2. `accessor` keyword REQUIRED on every @property + @state field per
   Phase 6 D-78 (TC39 2023-11 standard decorators under Vite 8 +
   Rolldown). Drop accessor and reactivity silently breaks.

3. `composed: true` REQUIRED on both events per Pitfall 4 — without
   it, host listeners on document never fire.

4. Theme prototype-pollution guard: `delete parsed.__proto__` per
   Security Domain "Prototype pollution via JSON theme" mitigation.

5. The route-restriction logic from EMBED-06 Open Q6 (RESEARCH §6
   line 584): when modules attribute doesn't include the destination
   entity, the route enter hook should redirect to the first allowed
   module (WARNING #6 — Plan 07-04 _composedEnter helper checks the
   modules whitelist and calls `routes.goto('/orgs/{orgId}/' + firstAllowed)`
   when entity is not in the CSV; Plan 07-08 adds a test mounting
   embed with `modules="agents,skills"` + hash `#open-routing/orgs/{id}/channels`
   and asserting redirect to agents within 100ms). embed-element just
   forwards the attribute.

6. The empty render output when `!this._client` (mid-mount or invalid
   transition) is intentional — prevents the shell from mounting
   with a null client (which would crash downstream component
   fetches).

7. Iteration-2 BLOCKER #1 ordering invariant: `_tryWireHashAdapter`
   assigns `shellEl.routerAdapter` BEFORE `shellEl.routingMode =
   'hash'`. Reversing this order would cause shell.firstUpdated to
   run with `routerAdapter === undefined`, silently failing the
   hash-mode wiring. The `@query` decorator + firstUpdated ordering
   in Lit guarantees the shell exists when this method runs because
   firstUpdated fires AFTER the first render commits the
   `<or-catalog-shell>` to shadowRoot.
