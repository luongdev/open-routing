```typescript
private async _tryStartHashAdapter(): Promise<void> {
  await this.updateComplete;
  const shell = this.shadowRoot?.querySelector('or-catalog-shell') as
    (HTMLElement & { routerAdapter?: { start: () => void; stop: () => void }; _routes?: unknown }) | null;
  if (!shell) return;
  // Shell exposes _routes (the @lit-labs/router Routes instance) as a
  // private field. We need it for the adapter constructor. Use a
  // type assertion + runtime check (Phase 6 shell field is named
  // `_routes`; if Plan 07-04 renames it during refactor, fix the
  // assertion here).
  const routes = (shell as unknown as { _routes: import('@lit-labs/router').Routes })._routes;
  if (!routes) return;
  this._hashAdapter = new HashRouterAdapter(routes);
  shell.routerAdapter = this._hashAdapter;
  // Shell's connectedCallback may have already finished; the adapter
  // needs start() called manually if shell already connected. Plan
  // 07-04 wires shell.connectedCallback to call routerAdapter.start()
  // only if it was set BEFORE connect. Here, set after connect — so
  // we call start() ourselves.
  this._hashAdapter.start();
}
```

**Private methods:**

```typescript
private _validateAndBuildClient(): void {
  if (!this.orgId) {
    this._validationError = 'org-id attribute required';
    this._client = null;
    return;
  }
  if (!UUIDV7_PATTERN.test(this.orgId)) {
    this._validationError = 'Invalid org-id attribute (expected UUIDv7)';
    this._client = null;
    return;
  }
  this._validationError = null;
  this._client = createApiClient({
    baseURL: this.apiBaseUrl,
    getOrgId: () => this.orgId,
  });
  this._client.use(this._buildAuthExpiredMiddleware());
}

private _buildAuthExpiredMiddleware(): Middleware {
  return {
    onResponse: async ({ response, request }) => {
      if (response.status !== 401) return response;
      let requestId = '';
      try {
        const body = await response.clone().json();
        requestId = (body && typeof body === 'object' && 'request_id' in body && typeof body.request_id === 'string')
          ? body.request_id : '';
      } catch {
        // body not JSON; preserve empty requestId
      }
      const path = new URL(request.url).pathname;
      this._authExpired = { requestId, path };
      this.dispatchEvent(new CustomEvent('open-routing:auth-expired', {
        detail: { statusCode: 401, requestId, path },
        bubbles: true,
        composed: true,
      }));
      return response;
    },
  };
}

private _parseTheme(): void {
  if (!this.theme) {
    this._parsedTheme = '';
    return;
  }
  if ((NAMED_THEMES as readonly string[]).includes(this.theme)) {
    this._parsedTheme = this.theme as NamedTheme;
    return;
  }
  try {
    const parsed = JSON.parse(this.theme);
    if (parsed && typeof parsed === 'object' && !Array.isArray(parsed)) {
      // Reject prototype-pollution attempts (V8 — Tampering threat)
      delete (parsed as Record<string, unknown>).__proto__;
      this._parsedTheme = parsed as Record<string, string>;
      return;
    }
  } catch {
    // fall through to or-light default
  }
  this._parsedTheme = 'or-light';
}

private _dispatchRequestContext(): void {
  this.dispatchEvent(new CustomEvent('open-routing:request-context', {
    detail: {
      orgId: this.orgId,
      apiBaseUrl: this.apiBaseUrl,
      theme: this.theme,
      modules: this.modules,
    },
    bubbles: true,
    composed: true,
  }));
}

private _dismissAuthExpired(): void {
  this._authExpired = null;
}
```

**Critical Phase 7 implementation notes:**

1. Shadow DOM mode is `'open'` — Lit's default. CONTEXT Discretion
   recommends open so Playwright assertions + host querySelector
   debugging work. No `attachShadow` override needed.

2. `accessor` keyword REQUIRED on every @property + @state field per
   Phase 6 D-78 (TC39 2023-11 standard decorators under Vite 8 +
   Rolldown). Drop accessor and reactivity silently breaks.

3. `composed: true` REQUIRED on both events per Pitfall 4 — without

4. Theme prototype-pollution guard: `delete parsed.__proto__` per
   Security Domain "Prototype pollution via JSON theme" mitigation.

5. The route-restriction logic from EMBED-06 Open Q6 (RESEARCH §6

   what user navigates to + sidebar filtering prevents listing.

6. The empty render output when `!this._client` (mid-mount or invalid
   transition) is intentional — prevents the shell from mounting
   with a null client (which would crash downstream component
   fetches).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host HTML attributes → element reactive state | org-id, theme, modules untrusted strings (any host page can write any value) |
| theme JSON parse → CSS custom properties | JSON.parse is safe but prototype pollution + CSS injection threats need guards |
| 401 response body → auth-expired event detail | response.json() may parse arbitrary content; only request_id extracted as string |
| customEvents → host document | composed:true exposes embed lifecycle; only whitelisted event names + opaque detail |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-02 | Input Validation / Tampering | Malformed org-id attribute reflected in error message | mitigate | Lit's html`` template auto-escapes interpolated strings; error message uses fixed copy ("Invalid org-id attribute (expected UUIDv7)") — never echoes attribute value. Test in Plan 07-08 verifies no XSS via crafted org-id |
| T-7-04 | Information Disclosure | Embed Shadow DOM CSS leaks to host or vice versa | mitigate | Lit default `mode: 'open'` Shadow DOM; `:host { contain: content }` reinforces isolation; Playwright spec in Plan 07-09 verifies both directions |
| T-7-07 | Information Disclosure | open-routing:request-context detail may leak sensitive context across Shadow boundary | mitigate | detail object contains only orgId (host already knows), apiBaseUrl (host configures), theme (host sets), modules (host sets) — no auth tokens, no PII.
