APPEND to .github/workflows/ci.yml after web-bundle-size (or
elsewhere keeping web-* jobs adjacent):

```yaml
  web-e2e-embed:
    # D7-12 (Phase 7): Playwright matrix (3 hosts × 4 specs = 30 runs)
    # validates EMBED-04 Shadow DOM isolation, EMBED-02 X-Org-Id
    # propagation, EMBED-07 auth-expired event, EMBED-06 modules filter
    # across React 18, Vue 3, plain HTML hosts. retries: 1 absorbs
    # esm.sh CDN flakes (Pitfall — see 07-RESEARCH.md §Environment
    # Availability). Becomes required-status-check per D-30 LOCKED.
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with:
          version: 10
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm
          cache-dependency-path: web/pnpm-lock.yaml
      - name: pnpm install
        working-directory: web
        run: pnpm install --frozen-lockfile
      - name: cache Playwright browsers
        uses: actions/cache@v4
        with:
          path: ~/.cache/ms-playwright
          key: playwright-${{ hashFiles('web/pnpm-lock.yaml') }}
      - name: install Playwright chromium
        working-directory: web
        run: pnpm --filter @open-routing/embed exec playwright install --with-deps chromium
      - name: build embed bundle
        working-directory: web
        run: pnpm --filter @open-routing/embed build
      - name: run Playwright matrix (3 hosts × 4 specs)
        working-directory: web
        run: pnpm --filter @open-routing/embed test:e2e
      - name: upload Playwright report on failure
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: playwright-report
          path: web/apps/embed/playwright-report/
          retention-days: 7
```

The artifact upload on failure preserves the HTML report (which
Plan 07-01 playwright.config.ts emits via `[['list'], ['html', { open:
'never' }]]`). 7-day retention covers a typical debug cycle.

Per CLAUDE.md HARD RULE: only the leading WHY comment block. Step
names are intention-revealing.

`actions/cache@v4` is pinned to major; key on pnpm-lock.yaml hash
(stable across PRs except when deps change — cache invalidates only
when Playwright version bumps).

Note on retries: Playwright config sets retries: 1 (Plan 07-01); CI
inherits. If a spec flakes once, Playwright retries automatically;
if both attempts fail, the job fails — required-status-check blocks
merge per D-30 LOCKED.
