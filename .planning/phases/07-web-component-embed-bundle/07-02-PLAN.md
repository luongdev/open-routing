Function `NewCORS(allowedOrigins []string) func(http.Handler)
http.Handler` — returns `cors.Handler(cors.Options{
AllowedOrigins: allowedOrigins, AllowedMethods: []string{"GET",
"POST", "PATCH", "DELETE", "OPTIONS"}, AllowedHeaders: []string{"X-Org-Id",
"Content-Type", "Idempotency-Key", "Accept-Language"},

automatically (RESEARCH §1 finding 3 verified in cors.go source — no
OptionsPassthrough means preflight returns 200 + headers and does NOT
call next.ServeHTTP). Embed v0.1 uses stub auth (X-Org-Id header from
trusted host); no cookies cross-origin → `AllowCredentials: false`.
`MaxAge: 300` (5 min) reduces preflight chatter.

Single comment block above NewCORS explains WHY ordering matters (not
WHAT — per CLAUDE.md HARD RULE): "cors.Handler short-circuits OPTIONS
without OptionsPassthrough — verified in go-chi/cors source. Placing

NOT restate what the code does.
