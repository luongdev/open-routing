# Plan 09 — orgDB SQL Inspector Hardening

**Gap source:** 01-REVIEWS.md (Codex HIGH-1, HIGH-2, HIGH-3-partial; Gemini MEDIUM)

**Goal:** Make `SQLChecker` reject any DML that does not bind `org_id` in the WHERE clause (not just anywhere in the AST), reject DDL without bypass, and make `OrgDB.QueryRow` return a typed error instead of panicking in `ValidationError` mode.

## Context

Three reviewers flagged the same root cause: `containsOrgIDColumnRef` checks for `sval:"org_id"` anywhere in the serialised protobuf AST. This produces:

- **False-positive (Gemini):** `SELECT 'org_id' AS alias FROM _scaffold` contains the literal string `org_id` as an `A_Const.sval`, not a `ColumnRef`. Inspector accepts it — incorrect.
- **False-negative (Codex HIGH-1):** `SELECT id, org_id FROM _scaffold` has `org_id` as a projection column (a `ColumnRef` in the target list, not in a WHERE predicate). Inspector accepts it — **actual cross-org leak vector for future queries**.

Codex HIGH-2: The default DDL `accepted` path means `DROP TABLE _scaffold` through normal OrgDB (no bypass) would silently pass the inspector. It is blocked earlier by the ctx org_id check, but the defence-in-depth layer is missing.

Codex HIGH-3-partial: `OrgDB.QueryRow` panics even in `ValidationError` mode, violating the prod "return error" contract.

<action>
Replace the `containsOrgIDColumnRef` function and update `classify()` to use a WHERE-clause-scoped predicate walk. The new logic checks whether `org_id` appears as a `ColumnRef` **inside the WHERE clause** of SELECT/UPDATE/DELETE, not anywhere in the full AST serialisation string.

**1. Remove the `strings` import** (no longer needed after this change).

**2. Replace `containsOrgIDColumnRef` with two new unexported functions:**

```go
// isOrgIDColumnRef returns true when the ColumnRef's last field is "org_id".
// ColumnRef.Fields is a []*Node where each node is typically Node_String_
// (for simple names) or Node_A_Star (for *). Only the last field is the
// column name; earlier fields are table qualifiers (e.g. "a" in a.org_id).
func isOrgIDColumnRef(cr *pg_query.Node_ColumnRef) bool {
    fields := cr.ColumnRef.GetFields()
    if len(fields) == 0 {
        return false
    }
    last := fields[len(fields)-1]
    s, ok := last.Node.(*pg_query.Node_String_)
    return ok && s.String_.GetSval() == "org_id"
}

// whereContainsOrgIDRef recursively walks a WHERE-clause node tree and returns
// true when any ColumnRef named "org_id" is present. Handles:
//   - ColumnRef  — leaf: check the field name
//   - BoolExpr   — AND/OR/NOT: recurse into Args
//   - A_Expr     — comparison (=, >, IN, etc.): recurse into Lexpr and Rexpr
//   - SubLink    — correlated subquery: recurse into the subselect's WHERE
// All other node types are ignored (no org_id ColumnRef can hide inside them
// in any well-formed SQL the application would emit).
func whereContainsOrgIDRef(node *pg_query.Node) bool {
    if node == nil {
        return false
    }
    switch n := node.Node.(type) {
    case *pg_query.Node_ColumnRef:
        return isOrgIDColumnRef(n)
    case *pg_query.Node_BoolExpr:
        for _, arg := range n.BoolExpr.GetArgs() {
            if whereContainsOrgIDRef(arg) {
                return true
            }
        }
    case *pg_query.Node_AExpr:
        return whereContainsOrgIDRef(n.AExpr.Lexpr) ||
            whereContainsOrgIDRef(n.AExpr.Rexpr)
    case *pg_query.Node_SubLink:
        if sub := n.SubLink.GetSubselect(); sub != nil {
            if sel, ok := sub.Node.(*pg_query.Node_SelectStmt); ok {
                return whereContainsOrgIDRef(sel.SelectStmt.WhereClause)
            }
        }
    }
    return false
}
```

**3. Update `classify()` to use the new walker for SELECT/UPDATE/DELETE:**

In the `*pg_query.Node_SelectStmt, *pg_query.Node_UpdateStmt, *pg_query.Node_DeleteStmt` case, replace:
```go
if !containsOrgIDColumnRef(stmt) {
    return ErrSQLMissingOrgFilter
}
```
with:
```go
var whereClause *pg_query.Node
switch sv := stmt.Node.(type) {
case *pg_query.Node_SelectStmt:
    whereClause = sv.SelectStmt.WhereClause
case *pg_query.Node_UpdateStmt:
    whereClause = sv.UpdateStmt.WhereClause
case *pg_query.Node_DeleteStmt:
    whereClause = sv.DeleteStmt.WhereClause
}
if !whereContainsOrgIDRef(whereClause) {
    return ErrSQLMissingOrgFilter
}
```

Note: the outer `for _, raw := range tree.Stmts` loop still dispatches on `raw.Stmt` using the type switch. The inner WHERE extraction needs a second type switch on the same `stmt` node because `n` in the outer switch is the unused `default` blank. Restructure the outer switch to use a named variable:

```go
for _, raw := range tree.Stmts {
    stmt := raw.Stmt
    if stmt == nil {
        return ErrSQLMissingOrgFilter
    }
    switch stmt.Node.(type) {
    case *pg_query.Node_SelectStmt,
        *pg_query.Node_UpdateStmt,
        *pg_query.Node_DeleteStmt:
        var whereClause *pg_query.Node
        switch sv := stmt.Node.(type) {
        case *pg_query.Node_SelectStmt:
            whereClause = sv.SelectStmt.WhereClause
        case *pg_query.Node_UpdateStmt:
            whereClause = sv.UpdateStmt.WhereClause
        case *pg_query.Node_DeleteStmt:
            whereClause = sv.DeleteStmt.WhereClause
        }
        if !whereContainsOrgIDRef(whereClause) {
            return ErrSQLMissingOrgFilter
        }
    case *pg_query.Node_InsertStmt:
        ins := stmt.Node.(*pg_query.Node_InsertStmt).InsertStmt
        if !insertHasOrgIDColumn(ins) {
            return ErrSQLMissingOrgFilter
        }
    default:
        // DDL and utility statements must go through WithBypass.
        // If they reach the checker, bypass is absent — reject.
        return ErrSQLMissingOrgFilter
    }
}
return nil
```

**4. Delete the old `containsOrgIDColumnRef` function** and the now-unused `"strings"` import.

**5. Update the comment on `classify()`** to replace the outdated "walk the parse tree for any ColumnRef" description with: "walk the WHERE clause for a ColumnRef named org_id; DDL/utility rejected unless bypass is present".
</action>

## Task 3 — Fix OrgDB.QueryRow: return typed error in ValidationError mode

<action>
**In `orgdb.go`:**

Add an `errRow` type that implements `pgx.Row` by deferring the stored error to `Scan`:

```go
// errRow is returned by QueryRow when preflight fails in ValidationError mode.
// Scan always returns the stored error, satisfying pgx.Row without panicking.
type errRow struct{ err error }

func (r errRow) Scan(_ ...any) error { return r.err }
```

Update `QueryRow` to panic only in `ValidationPanic` mode and return `errRow` in `ValidationError` mode:

```go
func (o *OrgDB) QueryRow(ctx context.Context, sql string, args ...interface{}) pgx.Row {
    if err := o.preflight(ctx, sql); err != nil {
        if o.mode == ValidationPanic {
            panic(fmt.Errorf("orgdb.QueryRow preflight failed: %w", err))
        }
        return errRow{err: err}
    }
    return o.pool.QueryRow(ctx, sql, args...)
}
```

Update the comment on `QueryRow` to reflect the new behaviour: panic in `ValidationPanic`, return `errRow` in `ValidationError`.

**In `orgdb_test.go`:**

Add a test that proves `QueryRow` in `ValidationError` mode returns an error from `Scan` instead of panicking:

```go
func TestOrgDB_QueryRow_ValidationError_NoOrg(t *testing.T) {
    t.Parallel()
    // ctx has no org_id — preflight returns ErrOrgIDMissingFromContext.
    ctx := context.Background()
    checker := NewSQLChecker()
    // We cannot construct a real pgxpool here (no DB), so use a nil pool.
    // QueryRow only reaches pool.QueryRow if preflight passes; preflight
    // fails on missing ctx org_id before touching the pool.
    o := NewOrgDB(nil, checker, ValidationError)
    row := o.QueryRow(ctx, `SELECT id FROM _scaffold WHERE org_id = $1`, "ignored")
    if err := row.Scan(new(string)); err == nil {
        t.Fatal("expected error from Scan on errRow, got nil")
    }
}
```

Note: `db.NewOrgDB(nil, checker, db.ValidationError)` uses a nil pool. The test is safe because preflight fails before `pool.QueryRow` is called.
