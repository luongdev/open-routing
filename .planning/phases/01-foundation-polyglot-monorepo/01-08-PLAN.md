    1. Open `https://github.com/<owner>/<repo>/settings/branches`
    2. Click "Add classic branch protection rule" (or edit existing rule for `main`)

    4. Check "Require status checks to pass before merging"

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner ↔ GitHub Actions cache | Cache key is `cache-dependency-path` content hash; if the hash changes, cache invalidates safely |
| Runner ↔ go.dev / npm registry | `go test` and `pnpm install` resolve dependencies from lockfiles; no `@latest` allowed in actions or migrate CLI install |
| Service container (postgres) ↔ runner | Only used by migration-drift job; container is ephemeral, dropped at job end; no host volume mounts |
| PR author ↔ main branch | Branch protection (D-31, configured in UI per branch-protection.md) requires all 6 status checks to pass before merge |
