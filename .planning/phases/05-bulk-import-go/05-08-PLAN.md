The cross-AI review pattern uses the BASH commands documented in the
project-wide CLAUDE.md HARD RULE. Phase 5 invocation adapts the pattern
for the COMBINED diff per orchestrator override:

```bash
# Combined diff: capture Phase 04.1 + Phase 5 changes from origin/main
git fetch origin
BASE=$(git merge-base HEAD origin/main)
git diff "$BASE"..HEAD > /tmp/combined-04.1+05-diff.patch

PROMPT='Review this diff for bugs, security, scope creep, missed edges,
PATCH semantics, transaction boundaries, and contract drift. The diff
covers TWO sequential phases (Phase 04.1 catalog identity normalization +
Phase 5 bulk import). Output sections: ## Summary / ## Concerns [HIGH/MED/LOW] /
## Suggestions / ## Verdict: READY | READY WITH FIXES | BLOCK.'

# Run both reviewers in parallel
(
  if ! { echo "$PROMPT"; cat /tmp/combined-04.1+05-diff.patch; } \
    | codex exec -m gpt-5.5 -c 'model_reasoning_effort="high"' --skip-git-repo-check - > /tmp/codex-review.md 2>&1; then
    {
      echo 'NOTE: gpt-5.5/high failed; fell back to Codex CLI default.'
      echo
      echo "$PROMPT"
      cat /tmp/combined-04.1+05-diff.patch
    } | codex exec --skip-git-repo-check - > /tmp/codex-review.md 2>&1
  fi
) &
(
  if ! { echo "$PROMPT"; cat /tmp/combined-04.1+05-diff.patch; } \
    | gemini -m gemini-3.1-pro-preview -p - > /tmp/gemini-review.md 2>&1; then
    {
      echo 'NOTE: gemini-3.1-pro-preview failed; fell back to Gemini CLI default.'
      echo
      echo "$PROMPT"
      cat /tmp/combined-04.1+05-diff.patch
    } | gemini -p - > /tmp/gemini-review.md 2>&1
  fi
) &
wait
```
