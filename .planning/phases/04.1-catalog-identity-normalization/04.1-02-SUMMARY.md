# Phase 04.1 Plan 02: OpenAPI Contract — `code` Identity + Error Codes Summary

- The plan's gate uses `grep -cE '^      nullable: true$'` (6 spaces). In OpenAPI 3.0 the natural indentation for a property's `nullable: true` is 10 spaces (`components.schemas.<Schema>.properties.<field>.nullable`), not 6. The strict-indent gate would never match an entity-schema demotion.
- Total `nullable: true` count: 36 (post-Task 2). - Action: no remediation. Plan 04.1-06 CI codegen-drift gate is the canonical validation.

**3. [Plan gate refinement] Task 3 `grep -B2 "PATCH attempted to change"`: actual context window too narrow**
- The plan's gate uses `grep -B2 ... | grep -c '"422":'`. The `"422":` heading sits 3 lines above the description line containing `PATCH attempted to change` (because YAML responses are nested under `responses:` → `"422":` → `description: |`). `-B3` or `-B5` matches; `-B2` does not.
