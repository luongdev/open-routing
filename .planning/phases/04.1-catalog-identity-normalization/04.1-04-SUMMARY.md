## What Each Handler Does Now (D04_1-19 + D04_1-20)

**CreateX (every entity):**

1. orgID + req.Body == nil guards (unchanged).
2. **NEW Layer 1**: `validateCodeFormat(req.Body.Code)` → 400 `invalid_body` / `invalid_code_format` if regex fails.
3. (channels.go only) **PRE-EXISTING** D-76 FK probe — runs AFTER Layer 1.
4. Existing Codex C1 + C4 + D-93 + D-55 + D-56 flow (unchanged).
5. **NEW InsertX param**: `Code: req.Body.Code,` placed after OrgID, before ExternalID.
6. **NEW 409 wire shape**: 23505 from `_org_id_code_key` → `duplicate_code`; 23505 from `ix_*_org_external_id` → `duplicate_external_id`. Wrapper is FLAT `api.ErrorResponse` for 5 of 6 entities; CreateAgent uses oneOf union (`FromErrorResponse` helper).
7. **NEW for CreateAdapter only**: `case 409: return api.CreateAdapter409JSONResponse(api.ErrorResponse{...})` arm — adapters had no 409 wrapper pre-04.1 (RESEARCH Pitfall 7 resolved).

**UpdateX (every entity):**

1. orgID + req.Body == nil guards (unchanged).
2. **NEW Layer 1**: when `req.Body.Code != nil`, run `validateCodeFormat(*req.Body.Code)` → 400 if regex fails. Skip if Code is absent (PATCH idiom).
3. (channels.go only) **PRE-EXISTING** D-76 FK probe (when `req.Body.DefaultQueueId != nil`).
4. **NEW Layer 2 (branched)**:
   - `req.Body.Code != nil`: pre-UPDATE `GetXByIdAnyVersion` fetches `stored`; if NoRows → 404; if other err → 500 `load_stored_failed`. Then `validateImmutableCode(stored.Code, *req.Body.Code)` → 422 `immutable_field` / `code` if differs.
   - `req.Body.Code == nil`: `stored` stays nil; Layer 2 entirely skipped.
5. Version-checked `qtx.UpdateX(...)` (unchanged).
6. **0-row 409 branch (reconciled with Layer 2)**:
   - `stored != nil`: reuse pre-UPDATE stored as `cur`; skip the post-UPDATE GetXByIdAnyVersion probe — saves one DB query when `code` is in body.
   - `stored == nil`: existing Phase 3 post-UPDATE probe runs unchanged (→ 404 vs 409).
7. **NEW 422 arm in err path**: `if status == 422 { return UpdateX422JSONResponse(api.ErrorResponse{...}), nil }` — surfaces FK / CHECK violations + the Layer 2 immutability rejection.
