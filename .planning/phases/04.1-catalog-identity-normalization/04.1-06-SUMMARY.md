#### Rule 1 — Auto-fixed lint regression

Plan 04 (commit `2bb3bfe`) introduced 2 lines of identical helper code with a staticcheck QF1001 (De Morgan's law) violation. `task lint` returned exit 1 on these:

```text
internal/catalog/testutil_test.go:327:22: QF1001: could apply De Morgan's law (staticcheck)
    if len(out) == 0 || !(out[0] >= 'a' && out[0] <= 'z') {
internal/state/testutil_test.go:491:22:   QF1001: could apply De Morgan's law (staticcheck)
    if len(out) == 0 || !(out[0] >= 'a' && out[0] <= 'z') {
```

**Fix (applied to both files):**
```diff
-    if len(out) == 0 || !(out[0] >= 'a' && out[0] <= 'z') {
+    if len(out) == 0 || out[0] < 'a' || out[0] > 'z' {
         out = append([]byte{'r'}, out...)
     }
```

Semantically identical (De Morgan: `!(A && B) ≡ (!A || !B)` ≡ `(out[0] < 'a' || out[0] > 'z')`). Post-fix, `task lint` exits 0.

**Why Rule 1 applies (vs. defer-to-follow-up):** Plan 06's acceptance criterion explicitly says "task lint exits 0 (no NEW lint errors introduced by Phase 04.1)." The fix is correctness-preserving, trivial (1 line × 2 files), and directly required to satisfy the gate. Deferring to a follow-up plan would defeat the gate's purpose.
